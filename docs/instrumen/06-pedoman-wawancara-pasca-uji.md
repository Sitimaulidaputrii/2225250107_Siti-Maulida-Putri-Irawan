# Pedoman Wawancara Pasca-Uji

**Tujuan:** membandingkan pengalaman beban kognitif siswa **setelah** memakai aplikasi dengan temuan wawancara awal (S01, 7 November 2026). Format pencatatan dan kode dibuat **sama** dengan laporan wawancara awal agar mudah dibandingkan.

**Peserta:** 3–5 siswa dari uji lapangan (kemampuan tinggi, sedang, rendah), termasuk S01 bila memungkinkan.
**Durasi:** ±20 menit, direkam dengan persetujuan siswa dan orang tua.
**Artefak pemicu:** aplikasi terbuka di HP siswa, soal −3x + 5 ≤ 11, satu soal cerita dari M6.

## Kode

| Kode | Arti |
|------|------|
| K | Konteks/pengalaman memakai aplikasi |
| IL | Beban intrinsik (kerumitan materi) |
| EL | Beban ekstrinsik (penyajian) |
| GL | Beban germane (yang membantu membangun pemahaman) |
| DS | Saran desain dari siswa |
